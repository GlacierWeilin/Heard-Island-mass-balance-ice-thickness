# Heard-Island-mass-balance-ice-thickness
This repository contains the Python code and shareable analysis products associated with the manuscript “Glacier changes across Subantarctic Heard Island revealed by remote sensing and ice thickness inversions” by Weilin Yang, Levan G. Tielidze, Regine Hock, Bethan J. Davies, Duane D. McKenna, Sarah S. Thompson, and Andrew N. Mackintosh.

We quantify glacier area change from 1947 to 2019, glacier mass balance from 2000 to 2019, and changes in glacier ice thickness and volume across Subantarctic Heard Island using multi-temporal glacier inventories, NASADEM, Pléiades digital elevation models (DEMs), and ice-thickness inversion. The mass balance analysis derives from glacier elevation differences from the co-registered NASADEM and Pléiades DEMs. Glacier ice thickness and bed topography are reconstructed for 1947, 1988, 2001, and 2019. DEM co-registration and spatial uncertainty propagation are based on [xDEM v0.2.3](https://github.com/GlacioHack/xdem.git), developed by the xDEM community, and the ice-thickness reconstructions use [GlabTop2-py v2.1.1]([https://github.com/GlacioHack/xdem.git](https://github.com/WilcoTerink/GlabTop2-py.git)), developed by Wilco Terink based on the GlabTop2 model of Frey et al. (2014).
